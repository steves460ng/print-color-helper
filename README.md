# CHROMA — 인쇄 색차 판정과 교정 기록

분광측색기로 얻은 타겟·인쇄물 CIELab 값을 반복 기록하고, 평균색의 ΔE76과 측정 흔들림을 확인하는 정적 웹 앱입니다. 외부 라이브러리·서버 API·로그인이 필요하지 않습니다.

## 실행

저장소에서 다음 명령을 실행하고 브라우저로 해당 서버를 엽니다.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

또는 `index.html`, `styles.css`, `app.js`를 함께 정적 웹 호스팅에 배포합니다. 최신 Chrome·Edge·Firefox·Safari를 권장합니다. 파일을 직접 여는 것보다 HTTP/HTTPS로 제공하면 저장 동작이 일관적입니다.

## 사용 순서

1. 작업명·용지·장비·광원/관찰자·측정 모드 등을 입력합니다. 타겟과 인쇄물은 같은 측정 조건을 사용하세요.
2. 타겟 Lab과 위치를 입력한 뒤 **측정값 추가**를 누릅니다. 반복 측정 후 **타겟 기준 확정**을 누릅니다.
3. 인쇄물 Lab을 반복 추가합니다. 추가 전 입력값은 판정에 반영되지 않습니다.
4. 평균색 간 ΔE76, 개별 색차, 표준편차, CMYK 환산 참고 방향을 확인합니다. 허용치는 해당 단계의 ΔE76 기준으로 입력합니다.
5. **다음 교정 시작**으로 새 묶음을 만들고 실제 조정 내용을 입력한 뒤 재측정합니다. 단계 선택으로 과거 결과도 확인할 수 있습니다.
6. JSON으로 백업하고, **보고서 인쇄 / PDF**로 보고서를 저장합니다. PDF 출력은 브라우저 인쇄 창에서 선택합니다.

측정값을 수정·삭제해도 이미 확정한 타겟 기준은 바뀌지 않습니다. 변경한 타겟을 다시 확정하면 새 기준 버전을 생성합니다. 현재 단계에 인쇄물 기록이 있으면 새 교정 단계를 만들며, 과거 단계는 당시 기준으로 평가합니다. **타겟 초안 비우기**는 초안만 비우며 기존 기준·교정 이력은 보존합니다.

교정 단계에는 해당 단계의 허용치와 첫 인쇄물 기록 당시 작업 정보를 보관합니다. 용지·인쇄·측정 조건이 달라지면 동일 통계 묶음에 섞지 마세요. 과거 단계를 선택한 상태에서도 측정값·메모·허용치 수정이 가능하므로 선택된 단계 이름을 확인하세요.

## 통계와 보정 안내

- 각 축의 평균, 최솟값·최댓값, `n−1`로 계산한 표본 분산·표준편차를 표시합니다. 측정 2개 미만의 분산·표준편차는 `—`입니다.
- `평균 ± 표준편차`는 신뢰구간이나 허용 오차가 아닙니다. 같은 위치 반복과 여러 위치 측정은 각각 장비 반복성과 시료 불균일성의 영향을 포함합니다.
- 평균색 간 ΔE76과 개별 색차의 평균은 다릅니다. 평균·최대 개별 색차도 함께 확인하세요.
- CMYK 값은 평균 Lab → D50 XYZ → D65 sRGB → 단순 CMYK 변환입니다. 실제 잉크 구성, 망점, 용지·인쇄 프로파일을 반영하지 않으며 실제 잉크 조정량으로 사용하면 안 됩니다.
- sRGB 색역 밖에서는 환산값에 잘림 경고를 표시하고 CMYK 방향 안내를 보류합니다. 색차는 원래 Lab으로 계산합니다.
- 판정은 사용자가 지정한 ΔE76 허용치에 따른 평균색 판정입니다. 특정 ISO 규격 준수를 자동 판정하지 않습니다.

## 저장·백업·보고서

기록은 현재 브라우저의 `localStorage`에 저장됩니다. 서버로 전송하지 않습니다. URL/포트, 브라우저, 기기가 다르면 같은 기록이 나타나지 않으며 브라우저 데이터 삭제 시 없어집니다. JSON 파일을 정기 백업하세요. CSV는 분석용이며 재복원에는 JSON을 사용합니다.

JSON 가져오기와 새 작업은 현재 작업을 교체하기 전에 확인합니다. 손상된 저장 기록은 자동으로 덮어쓰지 않습니다. 저장 실패 시 경고를 표시하고 JSON 백업을 권장합니다. 여러 탭에서 작업이 변경되면 덮어쓰기를 막기 위해 기존 탭의 저장을 중지하므로 백업 후 새로고침하세요.

보고서는 작업 정보, 선택한 단계의 요약·CMYK 안내, 타겟 초안, 교정 이력과 모든 확정 기준·단계의 통계 및 원본 기록을 포함합니다. 아직 추가하지 않은 Lab 입력값은 출력하지 않습니다. 브라우저 인쇄 설정에서 A4 세로를 선택하고 필요하면 머리글·바닥글을 끄세요.

## 검증

Python Playwright와 Chromium이 설치된 환경에서 실행합니다.

```sh
python3 -m unittest discover -s tests -v
```

기본 Chromium 경로는 `/usr/bin/chromium`입니다. 다른 환경에서는 `CHROMIUM_PATH`를 지정하세요. 테스트는 별도 임시 서버와 브라우저 컨텍스트를 사용하며 작업자의 저장 기록은 변경하지 않습니다.
