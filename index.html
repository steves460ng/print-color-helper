측정한 인쇄물의 원본 CMYK 값을 넣으세요. 권장값 = 현재값 + (기준 − 측정)으로 계산합니다.

근사값 안내

  • CMYK 값은 색 프로파일 없이 Lab(D50) → sRGB → CMYK 단순 공식으로 계산한 수학적 근사입니다. 실제 잉크, 용지, 인쇄 조건은 반영되지 않습니다.
  • 이 공식은 K를 최대로 뽑기 때문에 C, M, Y 중 하나는 항상 0이 되고, 명도 차이가 CMY 대신 K의 증감으로 나타날 수 있습니다.
  • sRGB 색역을 벗어난 색은 잘린 값으로 계산되어 차이가 실제와 다를 수 있습니다.
  • 조정값은 방향을 잡는 참고치입니다. 교정쇄와 재측정으로 반드시 확인하세요.

ΔE76 기준표

ΔE76판정특징
0 ~ 1.0구분 불가사람 눈으로 거의 구분 불가능. 숙련자도 나란히 놓고 봐야 겨우 알아챌 정도.
1.0 ~ 2.5합격선숙련된 관찰자는 인지 가능하나 일반인은 놓치기 쉬움. 품질관리 합격선으로 흔히 잡는 구간.
2.5 ~ 4.0뚜렷한 차이육안으로 뚜렷하게 다르다고 느껴짐. 브랜드 로고와 별색은 재작업 대상.
4.0 ~ 6.0불합격명확히 다른 색으로 인지됨. 일반 인쇄물에서도 대부분 불합격.
6.0 이상완전히 다른 색완전히 다른 색으로 인식되는 수준.

계산 결과가 있으면 해당 구간이 강조됩니다. 위 구간은 업계 통용 경험치이며, ISO 12647-2(ΔE76 기준) 규정값은 용지 3, CMYK 원색 솔리드 5, 전체 평균 3 이하·최대 6입니다.

ΔE₇₆ = √[(ΔL*)² + (Δa*)² + (Δb*)²] · Lab은 D50 백색점, 2° 관찰자 기준으로 해석하며 화면 표시와 CMYK 환산은 Bradford 순응으로 D65 sRGB를 거칩니다. 측정 조건(광원, 관찰각, 측정 모드)을 통일해야 값이 의미를 가집니다.
